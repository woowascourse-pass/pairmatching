## 구현할 기능 목록

---

### 입력

- [X]  기능 선택  
  ⇒ 1. 페어 매칭  
  ⇒ 2. 페어 조회  
  ⇒ 3. 페어 초기화  
  ⇒ Q. 종료
- [X] 과정, 레벨, 미션 입력

### 출력

- [X] 과정, 미션 출력
- [X] 페어 매칭 결과 출력


### 페어 매칭 규칙

1. 기본적으로 2명씩 매칭  
   ⇒ 대상이 홀수 일 경우만 마지막 크루를 마지막 조에 배치해서 3인 구성
2. 같은 레벨에서 이미 페어를 맺은 크루와는 다시 매칭이 될 수 없다.

### 페어 매칭 방법

1. `List<String>`으로 대상 준비   
   ⇒ `camp.nextstep.edu.missionutils.Randoms`의 shuffle 메서드로 섞기
2. 앞에서부터 2명씩 매칭하기  
   ⇒ 같은 레벨에서 페어로 만난적이 있으면 다시 shuffle  
   ⇒ 3회까지 매칭안되거나 or 매칭할 경우의 수가 없다면 ERROR


### 페어 매칭 기능
1. 이미 페어로 매칭된 기록이 남아있으면 안내문구 출력 후 입력에 따라 매칭 진행  
   ```
   매칭 정보가 있습니다. 다시 매칭하시겠습니까?
   네 | 아니오
   ```  
   ⇒ `아니오`로 선택 시 ⇒ 코스, 레벨, 미션을 다시 선택한다.
2. 페어 조회 기능
   - 과정, 레벨, 미션을 선택하면 해당 미션의 페어 정보를 출력한다.
   - 매칭 이력이 없으면 매칭 이력이 없다고 안내.
        ```
     [ERROR] 매칭 이력이 없습니다.
     ``` 


### 예외 처리

- [X] 올바르지 않은 입력을 했을 경우(기능 선택은 1,2,3,Q 만 가능)  
  ⇒ "[ERROR] 입력 값은 1,2,3,Q만 입력 가능합니다."
- [X] 과정이나 레벨, 미션값을 잘못 입력했을 때   
  ⇒ "[ERROR] 입력 정보가 잘못되었습니다."
- [X] 매칭에 실패샜을 경우    
  ⇒ "[ERROR] 매칭에 실패했습니다."
- [X] 매칭 재입력값을 예, 아니오가 아닌 다른 값으로 입력했을 때  
  ⇒ "[ERROR] 입력은 예, 아니오만 가능합니다."
- [X] 매칭이력이 존재하지 않을때  
  ⇒ "[ERROR] 매칭 이력이 없습니다."
